# NobodyWho JavaScript starter example

A small React example showcasing using [NobodyWho](https://nobodywho.ai) in the browser.

Try the demo [online](https://chat.nobodywho.ai).

Completely vibed.

## Developing

```sh
npm install
npm run dev
```

## Building for prod

```sh
npm run build
# Preview with:
npm run preview
```
